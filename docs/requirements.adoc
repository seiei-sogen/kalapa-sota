:toc:

== 概要

Rust と GPUI で作る Git GUI クライアント。Sourcetree のような操作感を目指す。
ワークツリー(`git worktree`)をネイティブに扱えることを特徴とする。

== 対象環境

* macOS
* Linux

== 技術スタック

* 言語: Rust
* UI: GPUI
* Git バックエンド: 未決定(git CLI 呼び出し / git2 / gitoxide から選定)

== UI

* デフォルトはダークモードとする。
* ブランチは色分けして見やすくする。グラフの線と、ブランチ名のラベルの両方に色を付ける。

== 初期スコープ(MVP)

最初は以下の 2 つだけを作る。その他の機能はロードマップに沿って順次追加する。

. 描画: コミット履歴とブランチグラフの表示
. ブランチの切り替え(checkout)
